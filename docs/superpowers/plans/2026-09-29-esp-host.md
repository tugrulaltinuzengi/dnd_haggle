# pazar on ESP32 (0.13.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** pazar 0.12.3 runs entirely on the ESP32 on COM11 (own Wi-Fi "Pazar", 192.168.4.1), and a new APK opens it with no setup.

**Architecture:** C++ firmware (PlatformIO, Arduino, ESPAsyncWebServer). The state is held as typed C++ structs (not one big JSON document, to keep heap use predictable) and serialized with ArduinoJson only at the edges (save/load, views, request bodies). `lib/engine` is a pure C++ port of `app/engine.js`. The HTTP API and the SSE snapshot shapes are identical to `app/server.js`, so `app/public` runs unchanged. Parity is proven by (a) 688 native engine vectors and (b) a black-box HTTP suite that runs against Node and against the ESP.

**Tech Stack:** PlatformIO (espressif32, framework-arduinoespressif32), ESP32Async/ESPAsyncWebServer + AsyncTCP, ArduinoJson 7, LittleFS, mbedtls (PBKDF2), Unity (native tests), Node 18 `node:test` (HTTP suite), Gradle 8.10.2 (APK).

**Spec:** `docs/superpowers/specs/2026-09-29-esp-host-design.md` (decisions E1–E12). **Branch:** `esp-host`. **Version shipped:** pazar 0.13.0.

**Spec amendment (E7):** state lives in typed structs, not one ArduinoJson document; the file format on flash is still one `data.json` with the same shape as Node's.

```cpp
void setup() {
  Serial.begin(115200);
  WiFi.mode(
#ifdef DEV_STA
    WIFI_AP_STA
#else
    WIFI_AP
#endif
  );
  WiFi.softAPConfig(IPAddress(192,168,4,1), IPAddress(192,168,4,1), IPAddress(255,255,255,0));

  WiFi.begin(STA_SSID, STA_PASS);
#endif

  LittleFS.begin(true);
  server.on("/api/ping", HTTP_GET, [](AsyncWebServerRequest* r) {
    r->send(200, "application/json", String("{\"ok\":true,\"version\":\"") + PAZAR_VERSION + "\",\"heap\":" + ESP.getFreeHeap() + "}");
  });
  server.onNotFound([](AsyncWebServerRequest* r) { r->send(200, "text/html", "<h1>pazar ESP</h1>"); });
  server.begin();
  Serial.printf("AP up: %s  ip=%s  heap=%u\n", AP_SSID, WiFi.softAPIP().toString().c_str(), ESP.getFreeHeap());
#ifdef DEV_STA
  Serial.println("DEV_STA: joining home Wi-Fi");
#endif
}
void loop() {
  dns.processNextRequest();
  static uint32_t t; if (millis() - t > 5000) { t = millis();
#ifdef DEV_STA
    if (WiFi.status() == WL_CONNECTED) Serial.printf("STA ip=%s\n", WiFi.localIP().toString().c_str());
#endif
  }
}
```
